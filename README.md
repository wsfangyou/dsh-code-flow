# dsh-code-flow

> 特化 agent 编程能力：**质量差与速度慢是同一个病** —— 没有门禁的流水线。

编程慢，九成时间不在「写」，在**返工**：没读就改、没规格就动工、没挖根因就重试、没证据就说完成。返工是编程最大的时间开销 —— 所以**快 = 一次做对**（first-cycle correctness），不是省步骤。本插件把专业工程师的流水线写进系统提示：**门禁按序，门不过不进下一阶段**。

## 成因 → 机制映射（设计出发点）

| # | 成因 | 对策 | 落点 |
|---|------|------|------|
| Q1 | **无模型先写**——没读代码就改 → 不一致、破坏约定 | P0 先读后写；grep 先于发明；先画爆炸半径 | 流水线 |
| Q2 | **无规格动工**——需求未收敛 → 返工黑洞 | P1 三行规格（需求/验收标准/方案）；一个阻塞问题只问一次 | 流水线 |
| Q3 | **症状式修补**——膏药摞膏药 → 缺陷复利 | P3 只修根因；调试协议：读全栈→单假设→最便宜判别实验→回归护栏 | 流水线 |
| Q4 | **完成无证据**——「应该能跑」→ 坏代码上线 | P6 完成=证据：跑了什么命令、真实输出是什么 | 流水线 |
| Q5 | **大爆炸式修改**——一次改500行 → 调试地狱 | P2 最小正确改动 + P4 由窄到宽验证 + P5 先跑通再优化 | 流水线 |
| S1 | **顺序错了**——猜代查、试代读 → 瞎摸 | 速度经济学：便宜证据优先，盲重试最贵 | 流水线 |
| S2 | **返工循环**——规格不清/根因没挖 → 最大时间黑洞 | **与 Q2+Q3 同源**：修质量 = 修速度 | — |
| S3 | **反馈环太粗**——大改+全量构建 → 慢环 | P4 增量窄环，一次修一个失败 | 流水线 |
| S4 | **反复推导已定决策**——原地转圈 | 速度经济学：一次定，线性执行；两败假设换假设不换参数 | 流水线 |

## 三档强度

| 档位 | 内容 |
|------|------|
| 均衡 balanced（默认） | 七段门禁 + 速度经济学 |
| 质量 quality | + 对抗性自审（边界/null/并发/版本）、修复必带回归护栏、全量相关套件才算绿 |
| 速度 speed | + 时间盒探索（三次搜不到就换手段）、最小可交付切片即停、等价选项立即定、不重开已定决策 |

> **注意**：三档的门禁**不可关** —— 速度档不是「少做验证」，是「把环收紧」。省门禁换来的时间，会被返工连本带利收回去。

## 三个机制

### 1. 纪律段 `code-flow:discipline`（order 默认 2190）

`systemPrompt.section` 注册，**每次提示构建现读** `code-flow` 设置：`enabled=false` → 返回空串（零贡献）。尾注恒在：任务指令/安全/真实性永远优先，**与真实代码库冲突时以代码库为准**。

### 2. 速度校准水龙（`system-prompt/assemble`，`{global, prepend}`）

下游装配完成后扫描各段文本的**反工程指令**触发词（`just make it work` / `quick and dirty` / `skip the tests` / `别想太多` / `尽快` / `凑合` …共10条 pattern），命中数 >0 才追加 `code-flow:calibration` 段：把「快」重定义为**快 = 一次做对**（通过门禁，而不是绕过门禁）。

- **只追加，绝不修改/删除宿主段**（原数组与各段对象原样保留）
- 纪律段自身对 pattern 表**零命中**（冒烟有防自激断言）
- `sanitize: false` 可整体关掉本机制

### 3. 设置行（设置 → 通用）

开关 + 三档选择，无需重启。默认**关闭**——不开启就零影响。

## 安装

`dsh-import` 导入 zip → 设置页开启。`cordis.patch.yml` 可配：

```yaml
config:
  sectionOrder: 2190   # 纪律段 order
  sanitize: true       # false = 关掉速度校准水龙
  extraRules: []       # 追加自定义团队规则（≤10 条、每条 ≤300 字，构建时净化）
```

可与 `dsh-think-guard`（思考纪律）叠加：一个管「想多久」，一个管「怎么写代码」。

## 测试

```bash
node test/smoke.mjs   # 纯契约：配置守卫/纪律段三档/防自激/水龙只追加+计数/设置行/字典对齐/包清单
```

## 安全边界

- 校准段**只追加**，宿主段一字不改
- 默认关闭，不开启零影响
- 尾注声明：纪律压不过任务指令、安全与事实；不许为流程篡改测试或输出
